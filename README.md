# KOOKOOKI · 선한국 팬페이지

비공식 팬메이드 웹사이트입니다.
아티스트 선한국의 활동과 콘텐츠를 아카이빙하기 위해 제작되었습니다.

## Features

* **About**: 프로필 및 소개

* **Schedule**: 공연 일정 및 D-day 관리

* **Works**: 작품 및 활동 아카이브

* **Gallery**: 프로필 및 페어컷 갤러리

## Tech Stack

* Vanilla HTML / CSS
* React (CDN)
* Supabase (데이터 관리)
* AWS S3 (이미지 저장)
* GitHub Pages

## Deployment

GitHub Pages를 통해 배포됩니다.

## Local Development

별도의 빌드 과정 없이 `index.html` 파일을 브라우저에서 실행하면 됩니다.
